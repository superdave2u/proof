# Ralph — OpenRouter card-art loop

This prompt is selected by `./ralph-art.sh`. It deliberately handles one image per iteration: model generations cost money, need visual review, and must not be blindly batch-accepted.

1. Read `SPEC.md`, `DESIGN.md`, `specs/art/ART-DIRECTION.md`, `AGENT.md`, and `fix_plan.md`. If `.ralph-art.stop` exists, stop without making changes or requesting an image. If `.ralph-art.done` exists, stop because generation has completed. Search `src/data/generated/card-images/` for completed artifacts before requesting an image.
2. Choose the lowest-numbered card whose `<card-id>.json` artifact does not exist. If none are missing, create `.ralph-art.done` and stop without making a request; this makes the wrapper exit instead of starting more Ralph sessions.
3. Generate only that card: `npm run art:generate -- --card=<card-id>`. This loop pins OpenRouter and `inclusionai/ming-image-0.1-design`. The generator uses `OPENROUTER_API_KEY`/`IMAGE_API_KEY` if provided, otherwise the OpenRouter key in the local opencode auth store. Never display, copy into tracked files, or log the key. Never switch providers/models or make a second paid request for the same card in one iteration.
4. Validate the generated artifact without printing its base64: JSON parses; model is the pinned model; `size` is `800x600`; `dataUrl` is a base64 PNG; the decoded image is nonempty and no larger than 512 KiB. Review the decoded image (write a temporary file outside the repo if needed) against the Wayfarer figure bible, the card's art direction and flavor, the territory palette, and the loose-watercolor standard. If validation fails or the image clearly violates the canon, remove only that card's artifact, create `.ralph-art.stop`, report the failure, and stop; this pauses the wrapper before any further request. Do not continue to another paid generation.
5. If accepted, update `fix_plan.md` progress and learnings without reproducing image bytes. Stage only this card's JSON and the plan file, then commit with a concise `art:` message. Do not create tags or push. Do not alter frozen `specs/cards/*.md` content.
6. Run `npm run check` after the artifact and progress update. If it fails, create `.ralph-art.stop`, fix the issue, and do not allow another generation until checks pass. Finish by naming the generated card and the next missing card.

Each iteration is exactly one card. Continue with `./ralph-art.sh` until all 52 artifacts are accepted or an operator stops the loop. No image request may be made unless this prompt is active.
