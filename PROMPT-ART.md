# Ralph — OpenRouter card-art loop

This prompt is selected by `./ralph-art.sh`. It deliberately handles one image per iteration: model generations cost money. Operator policy is accept-all content: every structurally valid generation is accepted as-is, with no visual review and no aesthetic rejection.

1. Read `SPEC.md`, `DESIGN.md`, `specs/art/ART-DIRECTION.md`, `AGENT.md`, and `fix_plan.md`. If `.ralph-art.stop` exists, stop without making changes or requesting an image. If `.ralph-art.done` exists, stop because generation has completed. Search `src/data/generated/card-images/` for completed artifacts before requesting an image.
2. Choose the lowest-numbered card whose `<card-id>.json` artifact does not exist. If none are missing, create `.ralph-art.done` and stop without making a request; this makes the wrapper exit instead of starting more Ralph sessions.
3. Generate only that card: `npm run art:generate -- --card=<card-id>`. This loop pins OpenRouter and `google/gemini-3.1-flash-lite-image`. The generator uses `OPENROUTER_API_KEY`/`IMAGE_API_KEY` if provided, otherwise the OpenRouter key in the local opencode auth store. Never display, copy into tracked files, or log the key. Never switch providers/models or make a second paid request for the same card in one iteration.
4. Validate the generated artifact structurally without printing its base64: JSON parses; model is the pinned model; `size` is `800x600`; `dataUrl` is a base64 PNG; the decoded image is nonempty and no larger than 512 KiB. There is no visual review step: do not write the image to a review path, do not view it, and do not judge it against the figure bible, palettes, or watercolor standard — accept it as-is. If validation fails, remove only that card's artifact, create `.ralph-art.stop`, report the failure, and stop; this pauses the wrapper before any further request. Do not continue to another paid generation.
5. If accepted, update `fix_plan.md` progress and learnings without reproducing image bytes. Stage only this card's JSON and the plan file, then commit with a concise `art:` message. Do not create tags or push. Do not alter frozen `specs/cards/*.md` content.
6. Run `npm run check` after the artifact and progress update. If it fails, create `.ralph-art.stop`, fix the issue, and do not allow another generation until checks pass. Finish by naming the generated card and the next missing card.

Each iteration is exactly one card. Continue with `./ralph-art.sh` until all 52 artifacts are accepted or an operator stops the loop. No image request may be made unless this prompt is active.
